# Verification Skill

Use this skill before declaring a task complete.

## Required process

- Determine which tests are relevant.
- Run focused tests first.
- Run broader checks when appropriate.
- Inspect the final diff.
- Confirm no secrets or unrelated files were changed.
- Report evidence.

A green result must come from an actual command execution.
